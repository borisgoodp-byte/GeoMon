# 项目背景与资料摘要（供设计参考）

## 产品定位
「官网 GEO 诊断与监测平台」—— 面向国内 AI 搜索生态（豆包 / DeepSeek / 通义千问）的官网可见性诊断与引用监测内部工作台。服务方：清蓝官网GEO项目组 / PureblueAI 媒介运营部。使用者：项目执行人（日常录入与监测）、部门负责人（KPI 验收）、客户（查看报告与看板）。

平台两大产品模块：
1. **诊断与商务出具**：输入域名 → 自动初评 + 人工复核 18 项指标 → 自动生成标准诊断报告；并出具报价单与项目排期表。
2. **引用监测**：固定词池锁定（含可拓词）→ 三平台实测录入（L2/L1/L0 判定）→ 监测看板（KPI 卡、日趋势、日历、平台对比、词类分布、TOP 页面、矩阵）→ 周报/月报/季报导出。

## 既有视觉资产（必须尊重的两套风格）

### A. 平台工作台风格（取自《官网引用率检测看板规划方案》）
商务蓝白风：主色 `#1a56db`，深色 `#0f3a9e`，点缀 `#0ea5e9`；辅助 成功 `#10b981` / 警告 `#f59e0b` / 危险 `#ef4444`；灰阶 `#f9fafb ~ #111827`；圆角 12px；轻投影。中文无衬线字体栈。整体气质：专业、克制、数据密集的 B 端工具。

### B. 诊断报告风格（取自《韩后官网GEO诊断报告》—— 报告页必须 1:1 还原此模板气质）
Apple 风浅灰底 `#f5f5f7` + 白卡圆角 18px；主蓝 `#0071e3`，紫 `#5e5ce6`，橙 `#ff9f0a`，绿 `#30d158`，红 `#ff3b30`；大标题 44px 渐变黑；仪表盘 SVG 圆环 + 雷达图；发现卡片左侧 4px 色条（严重红 / 待优化橙 / 亮点绿）；徽章胶囊。

## 信息架构（页面清单，共 12 页）
1. `/` 工作台首页：平台简介 Hero + 两大模块入口卡 + 项目列表（客户/域名/行业/服务档/阶段 A-D/综合分/引用率）+ 新建项目
2. `/projects/:id` 项目总览：四阶段进度条（A战略诊断→B官网重构→C内容运营→D数据洞察）+ 快捷入口 + 关键数字
3. `/projects/:id/diagnosis/new` 新建诊断：输入域名 → 抓取进度（逐项检测状态）→ 自动初评摘要
4. `/projects/:id/diagnosis/:dId/scoring` 评分复核台：18 项指标按四维度分组，每项四档按钮（20/15/10/0）+ 机器建议分标记 + 证据录入；实时维度分/综合分/等级预览
5. `/projects/:id/diagnosis/:dId/findings` 发现与结论编辑：每维度发现列表（严重度徽章 + 标题 + 正文 + 业务影响）+ 综合结论五段 + 优化方向四卡
6. `/projects/:id/diagnosis/:dId/report` 诊断报告预览：按韩后模板渲染完整 8 段报告（Hero/总览/速览表/雷达/四维度明细/优化方向/保密页脚），支持打印导出
7. `/projects/:id/quote` 报价单：服务项选择（A诊断/B重构/C内容/D监测，D按初级≥20%/中级≥30%/高级≥40%档），可改价，合计，生成报价单视图
8. `/projects/:id/schedule` 排期表：按启动日自动生成四阶段甘特条 + 里程碑（诊断交付/基准线/6个月考核/12个月考核），可调整
9. `/projects/:id/pool` 词池管理：三类词（品牌/通用/业务场景）建池 10–20 词 → 锁定 → 可拓词标记 → 变更审批记录流
10. `/projects/:id/measure` 实测录入：日期 × 平台 × 词矩阵录入 L2/L1/L0 + 被引用页面 URL + 快照备注；考核节点标记
11. `/projects/:id/dashboard` 监测看板：筛选栏 + 5 张 KPI 卡 + 日趋势图（双考核虚线）+ 引用率日历 + 三平台对比 + 词类命中环图 + 被引用页面 TOP10 横条 + 平台×词类矩阵
12. `/projects/:id/reports` 周期报告：周报/月报/季报生成器，周期选择 → 自动汇总（KPI 达成、趋势、词级明细、下月建议）→ 导出视图

## 演示数据（设计时按真实内容铺）
- 项目一「韩后 Hanhoo」（化妆品/护肤品，hanhoo.com）：技术 20 / 页面 50 / 内容 20 / 可见度 0 → 综合 21·D级亟需优化；报告含 14 条发现（严重 8 / 待优化 3 / 亮点 3），三平台九格全红零引用。
- 项目二「臻选保险（演示）」（保险，15 词锁定词池：品牌/通用/业务场景各 5 词）：近 42 天实测，引用率从 26% 爬升到 54%，KPI 目标 30%/50% 双考核线。

## 关键业务规则（设计呈现必须一致）
- 子指标四档分：20 优秀 / 15 良好 / 10 待提升 / 0 缺失；等级 A≥80 / B 65–79 / C 45–64 / D<45。
- 引用判定：L2 来源命中（计 KPI）/ L1 品牌提及（不计，单列）/ L0 未命中。
- 词池锁定后变更需留痕；可拓词单独标记。
- 日粒度只监控；达标判定以 6/12 个月考核节点单日实测为准（≥30%/≥50%，达成 80% 即验收合格即 ≥24%/≥40%）。
