# GeoMon 平台 · 修复打包说明

本包为修复后的完整工程（已剔除 node_modules、本地 MariaDB 运行目录与真实凭据）。

## 包含

- `app/` — 应用源码 + 已构建产物 `dist/`（前端分包产物 + 后端 bundle）
- `app/db/geomon_dump.sql` — 演示库全量导出（16 表 + 种子数据，640KB）
- `DESIGN_SPEC.md` / `info.md` / `plan.md` — 原始设计文档
- `geo-platform/` — 原包附带目录

## 三种用法

**A. 直接跑演示（无需 npm install）**

1. 准备一个 MySQL 8+/MariaDB 库，导入演示数据：
   `mysql -u root -p < app/db/geomon_dump.sql`（目标库名须为 `geomon`，或先 `CREATE DATABASE geomon` 再导入）
2. 在 `app/` 下新建 `.env`：`DATABASE_URL=mysql://user:pass@127.0.0.1:3306/geomon`
3. `cd app && node dist/boot.js` → http://localhost:3000

**B. 完整开发环境**

```bash
cd app
npm ci
cp .env.example .env   # 填 DATABASE_URL
npm run db:push        # 或导入 geomon_dump.sql 跳过建表+种子
npx tsx db/seed.ts     # 仅当未导入 dump 时
npm run dev            # http://localhost:3000
```

**C. 校验**：`npm run check` / `npm run lint` / `npm test` / `npm run build`
